# v1.1 — capability rewrite, clear-state, fail-open split, URI rules, installer hardening

status: DONE

## Delivered

1. Parse client `initialize`, strip `capabilities.textDocument.diagnostic`, and recompute Content-Length for that frame only.
2. Track forwarded diagnostic URIs so an empty clear can still pass after a URI becomes out of scope.
3. Distinguish framing failure (permanent fail-open) from one valid but unparseable JSON frame (pass only that frame, then resume filtering).
4. Canonicalize local `file:` paths through the deepest existing ancestor and use component-based containment.
5. Record root evidence and accept validated `workspaceFolders` as additional roots.
6. Harden installer idempotency/status/uninstall behavior without editing plugin-cache files.
7. Add real `typescript-language-server` integration coverage.
